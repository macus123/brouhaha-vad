NOISE LIBRARY
============

This directory contains standardized noise profiles at different SNR levels.

standard_noise_-20dB.wav: Noise at -20 dB SNR
standard_noise_-10dB.wav: Noise at -10 dB SNR
standard_noise_0dB.wav: Noise at 0 dB SNR
standard_noise_10dB.wav: Noise at 10 dB SNR

mixed_snr_noise_library.wav: A single file with sections at different SNR levels
  Sections: -20 dB, -10 dB, 0 dB, 10 dB
